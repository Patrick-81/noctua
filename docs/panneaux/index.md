# Panneaux — mode d'emploi

{: .fs-5 }

Chaque mode de la barre du haut n'affiche que les panneaux qui servent à ce moment de la nuit. Clique à gauche pour le pas-à-pas d'un mode — chaque page a la même structure : **rôle → pas-à-pas → capture → encadré astro → pièges → photo à venir**.

* 📷 Les photos existantes (`docs/screenshots/*.png`) sont intégrées. Les blocs `📷 à venir` sont les prises prévues (même cadrage sombre, 1920×1080).
* Les encadrés bleus renvoient aux [fiches astro-techniques](../astrotech/) pour le *pourquoi*.
